# 14. Datenbankzugriff über sqlc

**Status:** Angenommen (Wunsch des Betreibers)

## Kontext
Der Zugriff war zuerst handgeschriebenes SQL mit `pgx` im Go-Code.

## Entscheidung
SQL steht in `db/queries/`, `sqlc generate` erzeugt daraus typisierten Go-Code in `internal/db/`. Der generierte Code wird nicht von Hand geändert. Im übrigen Go-Code steht kein SQL.

## Alternativen
- **Handgeschriebenes pgx:** keine Prüfung gegen das Schema, Tippfehler fallen erst zur Laufzeit auf.
- **ORM:** verdeckt das SQL, passt schlecht zu JSONB und Mengenoperationen.

## Folgen
Nach jeder Änderung an Abfragen oder Migrationen muss `sqlc generate` laufen. sqlc lässt sich ohne C-Compiler bauen (`CGO_ENABLED=0`). Tests dürfen weiterhin direktes SQL für Testdaten und Prüfungen nutzen.
